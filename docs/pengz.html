一定會進化嗎？

只要沒養死，一定會長到成熟期。成熟期以上時間到沒達成條件就不會再進化，之後掉心和便便速度加倍。

合體（ジョグレス）規則
  • 所有成熟期、完全體，以及部分究極體可以合體。狀態畫面 info 的「J○」代表可以合體。
  • D 對戰 → JOGRES → 選 BACK UP 或 CONNECT。
  • BACK UP：跟備份中的怪獸合體。成功後備份的怪獸會消失。
  • CONNECT：跟另一台 Digimon Pendulum COLOR 連線合體，兩台會各自依自己的組合進化。「JOGRES」顯示時接上接頭，其中一台按 A 或 B，出現「OK!」就成功。
  • 組合不對會顯示「MIS MATCH」。
  • 不消耗 DP，也不需要 DP 滿。合體夥伴不會影響進化後的數值，只決定變成誰。
  • 合體只能跟 Pendulum COLOR 系列連線；Digital Monster COLOR 只能通信對戰。
  • 表中「其他版本」＝和非哥吉拉版的 Pendulum COLOR 合體時的結果。

A. 狀態（STATUS／ALBUM）

  • STATUS：A／B 翻頁看 年齡・體重 → Hungry（飢餓）→ Strength（力量）→ G-Cell → DP（活動力，對戰用）→ info → 勝率。
  • info：B○＝可以對戰、J○＝可以合體。
  • ALBUM：養過的怪獸（B 看特寫）。沒養過的只顯示編號，部分要解鎖才出現。
  • 體重到 99G 會生病；幼年期Ⅰ 體重不會變。

B. 食物

  • 肉（エサ）：飢餓 +1 心、體重 +1G。滿心就不能再餵。餵到 4 心全滿，掉心計時暫停 60 分鐘。
  • 蛋白質（プロテイン）：力量 +1 心、體重 +2G、G細胞 −2 點。每 4 個：DP +1、戰敗受傷率 +2%。
  • 飢餓 0 時不能對戰。

D. 對戰（BATTLE／JOGRES）

  • BATTLE → QUEST：任務模式，見「關卡」分頁。
  • BATTLE → CONNECT → PENDULUM：和 Pendulum COLOR 對戰，要先搖晃。
  • BATTLE → CONNECT → DIGIMON：和 Digital Monster COLOR／Digivice COLOR 對戰，不用搖。

E. 廁所

清便便。累積 8 坨會生病。幼年期Ⅰ 每 3 分鐘、幼年期Ⅱ 每 60 分鐘、成長期～完全體每 90 分鐘、之後每 120 分鐘拉一次。

F. 電燈（LIGHT／COLD／CHANGE）

  • LIGHT：開關燈。關燈時只能操作狀態和電燈圖示。
  • COLD：冷凍暫停，不老化、不進化、不掉心、不呼叫。再做一次解除；解除後掉心、便便計時從頭算。
  • CHANGE：備份／替換。幼年期Ⅰ不能備份。換回來的怪獸飢餓、力量都是 0。
  • 冷凍中又做備份、按重置孔或關機，飢餓與力量會變成 0。

G. 治療

怪獸旁邊有對話框「…」＝生病、有骷髏＝受傷。進治療後選對應的圖示。

生病

死亡條件（同一形態內）

  • 生病 12 次，或受傷 12 次（兩者分開計算）

隨機遭遇事件

怪獸襲來

  • 白天在主畫面時，哥吉拉主題曲響起＝怪獸襲來。
  • 按 A 或 B 應戰；按 C 或放著一段時間＝迴避。
  • 打法同任務模式。勝利 G細胞大增（完全體 +24、究極體 +32 點）。
  • 襲來時呼叫燈不會亮；DP 為 0 時就算應戰也不會開打。

其實不是隨機

  • 每隻怪獸有「時間組」和「對手組」。
  • 時間組決定每天幾點發生。
  • 對手組決定順序。每發生一次遭遇、或每進入一次訓練就換下一個。
  • 輪到「無」＝那個時間不會發生；清單跑完從頭開始。
  • 冷凍、備份、關機會讓清單回到第 1 個。

把時鐘調到遭遇時間前 1 分鐘，等它自己跳到那一分鐘就會觸發。輪到「無」時可以先進訓練再取消來跳過。

關卡

任務模式規則

  • D 對戰 → BATTLE → QUEST → 選關卡。沒打倒上一關 BOSS，下一關不會出現。
  • 每回合開打前要搖晃（同訓練）。
  • 雙方各 3 HP：一般命中 −1、Super Hit −2，先歸零的輸。
  • 輸一場＝整關失敗，要從第一回合重來。
  • 每一回合算 1 場對戰，並消耗 1 DP。
  • 攻擊模式：對手 5 次攻擊，灰色＝1 發、紅色＝2 發（Super Hit）。
  • 命中減：直接扣你的命中率。
